PANDUAN MENJALANKAN AMARIS DI XAMPP (MYSQL)

1. Ekstrak folder webrentalmobil ke C:\\xampp\\htdocs\\webrentalmobil (atau folder proyek yang diinginkan).
2. Jalankan Apache dan MySQL dari XAMPP.
3. Buka http://localhost/phpmyadmin
4. Buat database baru bernama: amaris
   Collation yang disarankan: utf8mb4_unicode_ci
5. Pastikan file .env di folder proyek berisi:
   DB_CONNECTION=mysql
   DB_HOST=127.0.0.1
   DB_PORT=3306
   DB_DATABASE=amaris
   DB_USERNAME=root
   DB_PASSWORD=
   Jika MySQL XAMPP Anda memakai password, isi DB_PASSWORD sesuai password MySQL.
6. Buka Terminal/CMD pada folder proyek, jalankan:
   php artisan optimize:clear
   php artisan migrate
   php artisan storage:link
   php artisan serve
7. Buka alamat yang ditampilkan oleh artisan serve (biasanya http://127.0.0.1:8000).

PENTING:
- Migrasi membuat struktur tabel di database MySQL amaris. Untuk database baru, jalankan `php artisan migrate`.
- Jangan jalankan `php artisan migrate:fresh` jika ada data yang ingin dipertahankan karena perintah itu menghapus semua tabel.
- Fitur upload Barcode BBM ada di Admin > Armada > Tambah/Edit Unit, bagian "Barcode BBM". Format yang diterima JPG, PNG, WEBP maksimal 4 MB.
- Barcode unit otomatis yang sudah ada tetap dipertahankan; upload Barcode BBM adalah gambar tambahan yang tersimpan pada data armada.
- Fitur dan file proyek lainnya tidak sengaja dihapus. Folder .git tidak disertakan dalam paket untuk mengurangi ukuran arsip.
